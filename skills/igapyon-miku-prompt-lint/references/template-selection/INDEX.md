# Template Selection References

Use these files only for optional prompt skeleton assistance after `igapyon-miku-prompt-lint` has already been activated for lint, audit, diagnosis, or review.

Start with the [workflow](workflow.md). It defines when to read the skeleton
types, the selected template, and the handoff rules. Follow its read order and
conditions; do not load this optional branch for an ordinary review.

After choosing a skeleton type, read only the matching file under `templates/prompt-skeletons/`.

# Repository/Harness Anti-Patterns

Use [../rule-contract.md](../rule-contract.md). Apply these only to supplied
repository/harness files.

## repository/maintainer-first-readme

Default severity: `Low`
Applies when: first-use value or activation is materially buried by maintainer detail.
Does not apply when: README is internal and a routed user guide exists.
Evidence required: README ordering and missing user guidance.
Target/runtime dependencies: None
Overlap/precedence: Repository-owned.
Why this is a problem: users cannot decide how to start.
Recommended fix: lead with value, activation, targets, and output.

## repository/index-contract-broken

Default severity: `Medium`
Applies when: declared `mikuIndex.required` metadata is missing or stale.
Does not apply when: no index contract exists.
Evidence required: declared contract plus missing/stale index.
Target/runtime dependencies: miku-indexgen when index exists
Overlap/precedence: beats routing; runtime links use agent-skill/broken-resource-route.
Why this is a problem: required consumers cannot discover the package.
Recommended fix: refresh an existing index; obtain explicit authority before creating a missing one.

## repository/shared-output-test-race

Default severity: `High`
Applies when: concurrent steps destructively mutate one output path.
Does not apply when: paths are isolated or execution is serialized.
Evidence required: concurrent mutation of the same path.
Target/runtime dependencies: None
Overlap/precedence: artifact identity is separate.
Why this is a problem: tests and release artifacts become flaky.
Recommended fix: isolate outputs or serialize mutation.

## repository/artifact-identity-gap

Default severity: `Medium`
Applies when: a tested artifact is overwritten or regenerated before release.
Does not apply when: identity is verified after the final generation.
Evidence required: build sequence and artifact paths.
Target/runtime dependencies: None
Overlap/precedence: not a concurrency race.
Why this is a problem: the released artifact was not the tested artifact.
Recommended fix: verify identity after final generation.

## repository/nonreproducible-generated-artifact

Default severity: `Medium`
Applies when: identical inputs produce materially different generated bytes.
Does not apply when: nondeterminism is documented and harmless.
Evidence required: repeated build output comparison.
Target/runtime dependencies: None
Overlap/precedence: artifact identity is separate.
Why this is a problem: verification and release trust weaken.
Recommended fix: stabilize generation and compare checksums.

## repository/evaluation-answer-leakage

Default severity: `High`
Applies when: an evaluation subject receives expected defects, answers, or fixes first.
Does not apply when: the information is necessary to the task, not an evaluation.
Evidence required: evaluator prompt and leaked expectation.
Target/runtime dependencies: None
Overlap/precedence: Repository/Harness-owned.
Why this is a problem: the evaluation no longer measures generalization.
Recommended fix: give raw artifacts first and compare expectations afterward.
